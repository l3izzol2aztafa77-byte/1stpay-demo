# 1st Pay — Demo

เว็บเดโมของ **1st Pay** ระบบชำระเงินโดย PLUS ONE BIZ CO., LTD. (Payment Facilitator)

## ลองใช้

เปิดลิงก์ GitHub Pages ของ repo นี้ แล้วลองได้เลย:

1. กด **สมัครใช้งาน** → กรอกเบอร์มือถือลาว เช่น `20 5512 3456` (หรือกด "ใช้อีเมลแทน")
2. รหัส OTP จะแสดงในกล่องสีทอง → กด **ใส่ให้**
3. ตั้ง PIN 6 หลัก 2 ครั้ง (ห้ามเลขซ้ำ เช่น 111111 หรือเลขเรียง เช่น 123456)
4. เข้าหน้าหลัก → ลองเปลี่ยนภาษา (ไทย / EN / ລາວ / 中文) และโหมดกลางวัน/กลางคืน
5. ออกจากระบบ → **เข้าสู่ระบบ** ด้วยเบอร์ + PIN · ลอง **ลืม PIN?** ก็ได้

## ข้อควรรู้

- นี่คือ **เดโม** — ไม่มีการส่ง SMS/อีเมล และไม่มีการเคลื่อนไหวเงินจริง
- ข้อมูลที่สมัครเก็บไว้ **ใน browser ของผู้ทดลองเท่านั้น** (localStorage) คนอื่นมองไม่เห็น และไม่ถูกส่งไปที่ใด
- กติกาความปลอดภัยเหมือนระบบจริง: OTP หมดอายุ 5 นาที · ผิดได้ 5 ครั้ง · ขอใหม่ทุก 60 วินาที · PIN ผิด 5 ครั้งล็อก 15 นาที
- ล้างข้อมูลเดโม: เปิด Console ของ browser แล้วพิมพ์ `__1P_DEMO_RESET()`
